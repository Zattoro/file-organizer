# 🗂 file organizer

Консольная утилита для наведения порядка в папках: сортировка, пакетное
переименование, поиск дубликатов и наглядный отчёт. Одна команда вместо
часа ручной работы в Проводнике.

## Возможности

| Команда | Что делает |
|---|---|
| `sort` | раскладывает файлы по подпапкам: по типам (фото/документы/чертежи...), по расширениям или по годам-месяцам |
| `rename` | пакетное переименование по шаблону: `{num}`, `{name}`, `{date}`, `{mtime}`, `{ext}` |
| `dupes` | находит дубликаты **по содержимому** (сначала сравнение размеров, потом SHA-256) и показывает, сколько памяти освободится |
| `report` | отчёт по папке: категории с диаграммой, топ-5 крупных файлов, «не трогали больше года» |

Во всех командах есть `--dry-run`: сначала смотрите план действий, потом подтверждаете.

## Установка

Python 3.10+, сторонних зависимостей нет (только стандартная библиотека).

## Примеры

```bash
# разложить загрузки по категориям (сначала показать, что будет сделано)
python organizer.py sort "D:\Загрузки" --dry-run
python organizer.py sort "D:\Загрузки"

# раскладка фото по месяцам
python organizer.py sort "D:\Фото" --by date

# переименовать сканы в "2026-04-15_01.jpg", "2026-04-15_02.jpg"...
python organizer.py rename "D:\скан" --pattern "{date}_{num}{ext}"

# найти дубликаты фото и удалить лишние копии
python organizer.py dupes "D:\фото"          # сначала показать
python organizer.py dupes "D:\фото" --delete # потом удалить

# чем занята папка
python organizer.py report "D:\Загрузки" --recursive
```

Пример вывода `report`:

```

Категория         файлов       размер

Архивы               63     3.2 ГБ  ███████
Изображения         880     1.4 ГБ  ███
Документы           105     0.6 ГБ  █
...
Не трогали больше года: 310 файл(ов), 4.2 ГБ — кандидаты в архив
```

## Структура кода

Один файл, четыре подкоманды на argparse, без зависимостей — по коду легко
добавлять свои правила сортировки (словарь `CATEGORY`) и новые режимы.
